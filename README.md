# ElectroDesign

Application Flutter native de conception de schémas électriques pour Android et Windows.

## Première base
- Éditeur de schéma sur grille.
- Bibliothèque initiale domestique, tertiaire, industrielle et nouvelle génération.
- Placement, sélection et suppression de symboles.
- Interface adaptative téléphone / ordinateur.

## Prérequis
Flutter stable, Android SDK pour APK, Windows + Visual Studio (Desktop development with C++) pour EXE.

## Démarrer
```sh
flutter pub get
flutter run
```

## Compiler
```sh
flutter build apk --release
flutter build windows --release
```

Cette base est le début du produit. Les connexions électriques, calculs, export de plans, bibliothèque technique étendue et conception 3D nécessitent des étapes dédiées et des tests.
